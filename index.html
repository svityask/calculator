Сохранение

Публикация на GitHub

Настройки хранятся в файле settings.json репозитория. После публикации все пользователи получат новые значения (GitHub Pages обновляется в течение 1–2 минут). Нужен персональный токен GitHub с правом записи в репозиторий (Contents: Read and write). Токен хранится только до закрытия вкладки.
