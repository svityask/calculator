# Калькулятор наливного пола INDASTRO

Мобильная веб-версия Excel-калькулятора (листы «ЭП гладкий» и «ПУ гладкий»).
Статическая страница: работает на GitHub Pages, без сервера.

## Режимы
- **Расчёт** — выбор системы (ЭП / ПУ), площадь, толщина, коэффициенты слоёв (в пределах,
  заданных администратором), запечатка по желанию. Итог, стоимость за м², комплекты по каждому
  материалу, проверка соотношения песок/пол. «Поделиться» отправляет расчёт текстом, «Сохранить PDF» печатает версию для клиента.
- **Админ** (пароль по умолчанию `indastro`, смените его сразу) — минимумы, максимумы и значения
  по умолчанию для толщины, площади и коэффициентов; цены, веса комплектов, плотности, расход
  грунта и лака, допустимые соотношения.

## Формулы (как в Excel)
`H = F/C·1000`, `J = Толщина · H/ΣH`, `Расход = J·C/1000` кг/м², `Кол-во = CEILING(Расход·Площадь; Вес компл.)`,
`Стоимость = Цена · Кол-во`. Грунт и лак — фиксированный расход. Запечатка в итог по умолчанию не входит (как в Excel, где итог = S7:S11).

## Где хранятся настройки
`settings.json` — опубликованные настройки для всех. Администратор может:
1. «Применить на этом устройстве» — только у себя (черновик);
2. «Опубликовать» — записать `settings.json` в репозиторий через API GitHub (нужен токен с правом Contents: write);
3. или «Скачать settings.json» и загрузить файл в репозиторий вручную.

`defaults.js` — исходные значения из Excel (кнопка «Сбросить к значениям из Excel»).

> Пароль проверяется в браузере и защищает только от случайных правок. Реальная защита — токен GitHub: без него опубликовать изменения для всех нельзя.
